# 有度茶舍：Google Drive 自动备份一次性授权

目前 APP 没有云端统一数据库。每台设备保存各自独立账本，自动备份也按照设备分文件，**备份不等于跨设备实时同步**。

## 无须提供 Google 账号密码

1. 在登录了你自己 Google 账号的浏览器打开 https://script.google.com/home/projects/create 。
2. 清空编辑器原有代码，粘贴本仓库 \`backup-apps-script.gs\` 全部代码并保存。
3. 打开左侧「项目设置」→「脚本属性」→「添加脚本属性」，名称 \`YOUDU_BACKUP_SECRET\`，值为你获得的独立备份密钥。**不要把密钥写进公开的 GitHub 源码。**
4. 点击「部署」→「新建部署」→类型「网页应用」，选择「执行身份：我」，访问权限「任何人」。此接口虽可被访问，但**只有带合法 HMAC 签名**的服务器请求可写入，且没有下载账本 API。
5. 首次部署时 Google 会要求授予这段脚本对你 Google Drive 的权限。认真确认脚本是你自己创建的并仅用于写入「有度茶舍－经营数据备份」文件夹。
6. 完成后只需将以 \`https://script.google.com/macros/s/\` 开头、以 \`/exec\` 结尾的**网页应用地址**告知助手（这个 URL 本身不包含密钥）。助手会把 URL 设置到 Render 环境变量 \`YOUDU_GOOGLE_BACKUP_URL\`，并测试第一笔备份。
7. APP 只有在**联网且打开或正在使用**时才尝试每日至少一次备份，并在更改数据后再次尝试。同一天同设备的备份更新同一 JSON 文件，次日生成新文件。

## 安全/限制

- Google Drive 与 ChatGPT 的现有连接不能让 Render 服务器自动调用你的 Drive，因此必须独立授权。
- 登录页的共享密码只用于 APP；Google 备份密钥只保存在 Render 环境变量和私人 Apps Script 项目脚本属性，**不能添加到网页前端**。
- 未设置完成以前，APP 显示「Google Drive 未授权」，不会冒充已经备份。
- 不应在两台设备分别创建同一笔订单后直接互相覆盖；此功能不会自动合并设备账本。
- 用户关闭所有设备或长时间离线时，无法保证无人运行状态下每日新备份。要实现全天候远程同步，需要持久化的服务端账本。
